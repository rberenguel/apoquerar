# Apoquerar

Portmanteau-ish of the Catalan words _pòquer_ and _apilar_.

This is a 100% Gemini created [1] version of Zach Gage's [_Pile up Poker_](https://www.puzzmo.com/game/pile-up-poker/) that you can play in [Puzzmo](https://www.puzzmo.com/).

The one in Puzzmo is _way_ better than this (the only comparison is the goal of the game), but this scratches the offline playing itch well enough.

[1]: I have tweaked some of the text, only.
